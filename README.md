# Exploratory Data Analysis (EDA) on Cars Dataset

This project focuses on Exploratory Data Analysis (EDA) using Python to understand and analyze a car dataset obtained from Kaggle. The dataset contains information about different cars, including manufacturer, model, year, engine horsepower, cylinders, transmission type, fuel economy, and price.

## Project Objectives

* Understand the structure and features of the dataset.
* Clean the data by removing duplicate records and handling missing values.
* Identify and handle potential outliers using the Interquartile Range (IQR) method.
* Analyze numerical and categorical variables.
* Explore relationships between car features and prices.
* Create meaningful visualizations to understand data patterns.

## Tools and Technologies

* **Python:** Programming language for data analysis.
* **Pandas:** Data manipulation and cleaning.
* **NumPy:** Numerical operations.
* **Matplotlib:** Data visualization.
* **Seaborn:** Statistical visualization and graphical analysis.

## Key Activities

1. Imported the required Python libraries.
2. Loaded and explored the Cars Dataset.
3. Checked data types and examined dataset characteristics.
4. Removed irrelevant columns and renamed selected features.
5. Identified and removed duplicate records.
6. Checked for missing values and handled them.
7. Used descriptive statistics to summarize numerical data.
8. Identified potential outliers using box plots and the IQR method.
9. Created histograms, bar charts, count plots, and scatter plots.
10. Used correlation analysis and heatmaps to explore relationships between numerical features.

## Learning Outcomes

Through this project, I gained practical experience in Python-based data analysis, data cleaning, statistical exploration, and visualization. I also learned how to identify patterns in datasets and examine relationships between car features and prices.

## Conclusion

This project demonstrates the importance of EDA in understanding data quality, discovering patterns, and preparing datasets for further analysis. It also strengthens my foundational skills in Python and data analytics.
